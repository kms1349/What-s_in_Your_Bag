# What's in Your Bag? 상황별 준비물 관리 프로그램

학교, 운동, 여행 등 상황별 준비물 목록을 만들고,
출발 전에 빠진 물건이 없는지 확인하는 Java 콘솔 프로그램입니다.

## 주요 기능

- 상황별 준비물 목록 생성·이름 변경·삭제
- 목록 생성 시 준비물 등록
- 준비물을 하나씩 확인하는 y/n 체크리스트
- 챙긴 물건 수와 안 챙긴 물건 수, 남은 준비물 출력
- JSON 파일을 통한 데이터 저장 및 불러오기

## 실행 환경

- Java JDK 설치 및 `java`, `javac` 명령 사용 가능
- Windows PowerShell 또는 명령 프롬프트
- Gson 2.13.2 — `lib` 폴더에 포함

## 실행 방법

### 1. 저장소 다운로드

```powershell
git clone https://github.com/kms1349/What-s_in_Your_Bag.git
cd What-s_in_Your_Bag
```

Git이 없다면 GitHub의 **Code → Download ZIP**으로 다운로드한 뒤
압축을 풀고 해당 폴더에서 터미널을 실행합니다.

### 2. 프로그램 실행

다운로드한 ZIP은 전체 압축을 푼 뒤 실행합니다.
`runWYB.bat`를 더블클릭하거나, 압축을 푼 폴더에서 아래 명령을 입력합니다.
배치 파일은 자신이 있는 폴더를 기준으로 컴파일하고 실행합니다.

PowerShell에서 다음 명령을 입력합니다.

```powershell
.\runWYB.bat
```

또는 직접 컴파일하고 실행할 수도 있습니다.
아래 명령은 프로젝트 최상위 폴더에서 실행합니다.

```powershell
javac -encoding UTF-8 -cp ".;lib\gson-2.13.2.jar" -d out *.java
java -cp "out;lib\gson-2.13.2.jar" project.WYB
```

## 사용 방법

### 준비물 목록 만들기

1. 메인 메뉴에서 `a`를 선택합니다.
2. 목록 이름을 입력합니다.
3. 준비물을 하나씩 입력합니다.
4. `0`을 입력하면 등록을 마치고 저장합니다.

### 목록 조회 및 관리

- 목록 번호: 해당 목록 조회
- `b`: 목록 이름 변경
- `c`: 목록 삭제
- `0`: 프로그램 종료

### 체크리스트 수행

1. 메인 메뉴에서 목록 번호를 입력합니다.
2. 준비물 메뉴에서 `a`를 선택합니다.
3. 각 준비물에 대해 챙겼으면 `y`, 챙기지 않았으면 `n`을 입력합니다.
4. 결과를 확인하고 Enter를 눌러 준비물 메뉴로 돌아갑니다.

`y/n`은 대소문자를 구분하지 않으며,
다른 값을 입력하면 같은 준비물에 대해 다시 질문합니다.

## 실행 예시

```text
노트북 챙겼나요? (y/n): y
충전기 챙겼나요? (y/n): n
지갑 챙겼나요? (y/n): y

챙긴 물건 수: 2개 / 안 챙긴 물건 수: 1개

[챙겨야 할 준비물]
- 충전기

Enter를 누르면 준비물 메뉴로 돌아갑니다:
```

## 데이터 저장

목록과 준비물은 실행한 폴더의 `preparation.json`에 저장됩니다.
프로그램 시작 시 해당 파일을 읽어 목록을 복원합니다.

목록 생성·이름 변경·삭제 시 전체 목록의 깊은 복사본에서
작업한 뒤, 파일 저장에 성공하면 실제 목록에 반영합니다.
저장에 실패하면 기존 목록을 유지합니다.

파일은 임시 파일에 먼저 기록한 뒤 원본 JSON을 교체합니다.

저장 형식 예시:

```json
[
  {
    "listName": "학교",
    "items": ["노트북", "충전기", "지갑"]
  },
  {
    "listName": "운동",
    "items": ["운동복", "물"]
  }
]
```

체크리스트의 y/n 응답은 파일에 저장하지 않으며,
체크리스트를 실행할 때마다 새롭게 확인합니다.

## 프로젝트 구조

```text
What-s_in_Your_Bag/
├─ WYB.java
├─ MainMenu.java
├─ ListManager.java
├─ PreparationList.java
├─ FileManager.java
├─ lib/
│  └─ gson-2.13.2.jar
├─ preparation.json
├─ runWYB.bat
└─ LICENSE
```

| 클래스 | 역할 |
|---|---|
| `WYB` | 프로그램 시작 |
| `MainMenu` | 메뉴 진행, 사용자 입력 및 체크리스트 결과 출력 |
| `ListManager` | 목록 추가·이름 변경·삭제 및 전체 목록 복사 |
| `PreparationList` | 목록 이름과 준비물 관리, 준비물 입력 검사 및 복사 |
| `FileManager` | Gson을 이용한 JSON 저장·불러오기 |

## 현재 제한 사항

- 목록은 최대 50개까지 생성할 수 있습니다.
- 각 목록에 준비물을 최대 50개까지 등록할 수 있습니다.
- 목록 이름은 전체 목록에서 중복될 수 없습니다.
- 준비물 이름은 같은 목록 안에서 중복될 수 없습니다.
- 준비물은 목록 생성 과정에서 등록하며,
  기존 목록에 준비물을 추가·수정·삭제하는 메뉴는 아직 없습니다.
- 현재 실행 안내와 배치 파일은 Windows 기준입니다.
